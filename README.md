# ev-charging-simulator — 云快充协议充电桩模拟器

基于云快充协议（V1.5）的直流充电桩终端模拟器，用于充电运营平台/网关的联调与回归测试。

仅依赖 Python 标准库，开箱即用，无需安装任何第三方包。

## 特性

- 完整模拟单枪充电生命周期：登录 → 心跳 → 计费模型协商 → 插枪握手 → BMS 参数配置 → 实时数据上报 → 充电结束 → 交易记录上报
- 支持平台远程启机 / 停机（0x34 / 0x36），自动应答确认帧
- 充电过程模拟：电表读数与金额按步长递增，SOC 渐进上升，BMS 需求报文周期发送
- 断线自动重连（指数退避），重连后自动恢复登录与心跳
- 控制台交互：输入 `stop` 手动停止充电并上报完整账单
- 帧编解码基于 Modbus CRC16，时间字段采用 CP56Time2a 格式

## 环境要求

- Python 3.8+（无任何第三方依赖）

## 快速开始

```bash
# 连接本地网关（默认 127.0.0.1:8882，桩号 77031000000001）
python mockPile.py

# 指定云平台地址与桩号
python mockPile.py --host 192.168.1.100 --port 8768 --pile 77031000009999

# 多枪桩，模拟第 2 枪
python mockPile.py --guns 2 --gun 2
```

启动后自动完成登录，进入心跳与实时数据上报循环。充电启动由平台远程下发（或按平台联调流程触发）；运行中在控制台输入 `stop` 可主动结束充电并上报交易记录。

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--host` | 云平台地址 | `127.0.0.1` |
| `--port` | 云平台端口 | `8882` |
| `--pile` | 14 位数字桩编码（BCD 编码传输） | `77031000000001` |
| `--guns` | 枪数 | `2` |
| `--gun` | 当前模拟的枪号 | `1` |

除命令行参数外，文件头部"默认配置"区还可调整：心跳间隔、实时数据上报周期、金额/电量递增步长与上限、协议版本号、程序版本号等。

## 支持的协议帧

| 类别 | 帧类型（上行 / 下行） | 说明 |
|------|----------------------|------|
| 登录 | 0x01 / 0x02 | 桩登录，含协议版本、程序版本、枪数等 |
| 心跳 | 0x03 / 0x04 | 周期心跳 |
| 计费模型 | 0x05 / 0x06、0x09 / 0x0A | 计费模型校验与全量请求 |
| 实时数据 | 0x12 / 0x13 | 周期上报电压、电流、SOC、电表读数等 |
| 充电握手 | 0x15 / 0x16 | BMS 握手报文 |
| 参数配置 | 0x17 / 0x18 | BMS 参数配置（最高电压/电流、能量需求等） |
| BMS 报文 | 0x1D / 0x23 / 0x25 | 充电中止、需求报文、总报文 |
| 远程启停 | 0x34 / 0x33、0x36 / 0x35 | 平台远程启机 / 停机及应答 |
| 充电结束 | 0x19 / 0x20 | 含结束原因、SOC、电表起止读数 |
| 交易记录 | 0x3B / 0x40 | 分时段电量与金额明细上报 |
| 运维交互 | 0x41 / 0x42 等 | 余额更新、参数/时间/计费设置应答、锁状态 |

命令码约定：奇数为桩上行帧，偶数为平台下行帧。

## 典型使用场景

- **网关联调**：Netty 网关开发期无需真实桩，即可验证帧编解码、会话管理与负载均衡
- **回归测试**：平台版本升级后，用固定桩号回放登录-充电-账单全流程
- **异常模拟**：通过断网/杀进程模拟桩离线重连，验证平台的会话恢复与订单补传逻辑
